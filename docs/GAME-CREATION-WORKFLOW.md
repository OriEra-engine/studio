# 玩家制作游戏全工作流 —— 每一层自由选择模型与 Agent

> 原则:**引擎/工作台提供骨架,AI 是骨架上的肌肉,每一块肌肉用户都能换。**
> 选择粒度 = 槽位(RFC-3),不是"全局一个模型"。Studio 页面 ↔ 工作流阶段一一对应,奥粒(Ori)全程在场。

## 一、全工作流七阶段总览

```
S0 准备 ─ S1 灵感 ─ S2 世界观 ─ S3 玩法 ─ S4 资产与剧情 ─ S5 试玩迭代 ─ S6 发布
   │         │         │          │          │             │           │
 模型中心   奥粒对话   AI剧情生成  模板库    L8生成+编辑器   运行+热替换   导出/分发
```

| 阶段 | 用户做什么 | AI 做什么(槽位) | Studio 入口 | 用户可换什么 |
|---|---|---|---|---|
| **S0 准备** | 硬件体检 → 选模型轨 | 推荐引擎按硬件/预算双轨推荐(云端/本地) | 模型中心 | **对话模型**(智谱/DeepSeek/Kimi/豆包/Ollama/不配=离线)、**每个任务槽的厂商与降级链** |
| **S1 灵感** | 说一句想做什么 | 奥粒(npc_dialog 槽)追问补全:题材/难度/时长;给 3 个玩法候选 | 奥粒抽屉 | **助手人格温度**(专业策划/损友/童话)、**追问深度** |
| **S2 世界观** | 一句话世界观 | AI 剧情生成(director 槽):前提 + 节拍(三幕式);可反复重摇 | 新建游戏向导·第 2-3 步 | **叙事框架**(5 个离线库)、**节拍数**、**重摇次数无限制**、不满意可换模型再生成 |
| **S3 玩法** | 选玩法模板 | 模板=确定性骨架(15 个离线库);奥粒解释每个模板适合什么故事 | 向导·第 1 步 | **玩法模板**、可导入玩法包(JSON,社区可扩展) |
| **S4 资产与剧情** | 精修节拍 | 单拍 AI 重写(director 槽)带前后文;[v0.4] L8 生成中心:一句话出 GLB/立绘(Tripo/Seedance/Seedream 槽)热替换进场景 | 剧情编辑器 / 生成中心(v0.4) | **生成模型按资产类型分槽**(角色/建筑/道具/视频各绑一家)、**重写指令自由文本** |
| **S5 试玩迭代** | 运行→玩→改 | 运行时 AI NPC 对话(npc_dialog 槽);剧情导演在线推进;金币/线索经济;[路线] reviewer 槽截图审校给改进建议 | 我的项目→运行(热替换免重启) | **NPC 人格/记忆**、**导演推进节奏**、**审校严格度** |
| **S6 发布** | 导出分发 | 存档打包(导出/导入);[路线] 一键构建独立网页版 | 项目详情 | 导出范围(存档/全项目) |

## 二、"每一层自由选择"总表(设计基准)

| 可换层 | 载体 | 现状 | 用户价值 |
|---|---|---|---|
| 对话模型(L7) | 模型中心 provider + 槽位路由 | ✅ 8 预设 | 按价格/隐私/质量自由换,厂商故障降级链保体验 |
| 生成模型(L8) | 生成中心槽位(v0.4) | 引擎侧已落地(Tripo/Seedance),Studio 待接 | 资产类型各选最优,风格资产锁一致性 |
| Agent 人格 | 奥粒设置 | v1 人格随 system prompt | 搭子风格自选 |
| 玩法骨架 | 模板库 | ✅ 15 模板 + 外置导入 | 确定性部分不被 AI 绑架 |
| 叙事结构 | 叙事框架库 | ✅ 5 框架离线 | 结构自由 |
| 降级策略 | 槽位 fallback 链 | ✅(RFC-3 路由表) | 断网/断供游戏照样做 |

三条不变量(治理红线):
1. **每个 AI 步骤都有离线兜底**(规则模板/占位资产)——拔掉所有模型,工作流仍可走通;
2. **选择是数据不是代码**——所有选择存配置,热切换生效,不重启;
3. **确定性骨架与 AI 增强分离**——玩法模板/叙事框架是确定性的,AI 只增强不绑架。

## 三、奥粒在流程中的介入点(v1 → v3)

- **v1(已实现)**:每阶段问答引导(规则模式兜底)、快捷指令直达 S0/S1/S2 入口、Ctrl+K 全流程键盘加速;
- **v2**:工具调用替用户执行——"帮我建一个雪原侦探游戏" → 自动选模板+生成剧情+建项目(写操作需确认);
- **v3**:S4 生成中心操作者(槽位路由可视化编辑)、S5 reviewer 审校回路、S6 发布向导。

## 四、与引擎/展示页的关系

- Studio 槽位 UI = `oriera-deliverables/showcase/index.html` 演示的同构实装(数据结构对齐 RFC-3 路由表);
- 引擎侧 L7 `ModelProvider`/L8 `GenerationProvider` 契约不变,Studio 只是它的第一个宿主;
- 厂商合作包(RFC-3/PARTNER-REVIEW/话术单)中承诺的"预设注册表/生命周期位/计量一致性"落进模型中心,演示页 → Studio → 引擎三层一致。
