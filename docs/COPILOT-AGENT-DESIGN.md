> 2026-10-20 实现并浏览器实测通过(降级路径/打字机/命令面板/Ctrl+J/历史落盘)。

## 一、定位:三层角色

奥粒是 **Studio 工作台级的用户辅助 agent**,是引擎"AI 内生"哲学在工作台上的壳:

| 期 | 形态 | 能力 | 状态 |
|---|---|---|---|
| **v1(本次)** | 对话助手 | 多轮对话(Tauri `copilot_chat` → L7 provider)、快捷指令、页面导航、打字机流式、规则降级 | ✅ 已实现 |
| **v2(下版)** | 操作助手 | 工具调用:替用户执行向导步骤(选模板/生成剧情/建项目)、读项目上下文做诊断 | 排期 |
| **v3(对齐 RFC-3)** | 引擎 L9 的壳 | 槽位路由表可视化编辑、生成中心(L8)一句话出 GLB、Director 联调 | 路线 |

关键架构决定:**奥粒不直连厂商 API**——所有调用走 Rust 侧 `copilot_chat` → 用户在模型中心配置的 provider(L7 边界)。好处:密钥不出平台壳、换模型零改动、与游戏内 NPC 用同一套计量/降级设施。

## 二、卡通形象:「奥粒 Ori」

- **名字**:奥 = OriEra 之奥;粒 = "元粒"——世界由元粒子生成,奥粒就是那颗帮玩家生成世界的粒子。昵称"小奥"。
- **视觉**(内联 SVG,零图片依赖,深色主题):
  - 蓝色圆形本体(径向渐变 #9fd0ff→#2e5fd0),头顶金色星尘天线(元粒子的"灵感接收器",闪烁动画);
  - 一对大眼睛(4.4s 周期眨眼),弧线微笑;本体高光椭圆增加体积感;
  - 外圈虚线轨道 + 两颗轨道粒子(14s 缓转;**思考时加速到 1.6s**——忙碌状态可视化的核心);
  - 悬浮呼吸(bob 3.6s);悬浮球右下角状态点:绿=provider 在线,灰=离线规则模式。
- **性格**:活泼但克制、短句、给步骤不超 6 条、不堆客套话(写进 system prompt,不是玄学)。
- **出现位置**:右下角 58px 悬浮球(常驻)→ 点击/Ctrl+J 展开 400px 右侧抽屉(不遮挡主内容,Esc 收起)。
- **离线人设**:未配置模型时自称"离线小奥",气泡挂「规则模式」标签——降级可见、不装懂(引擎 RuleProvider 同一哲学)。

## 三、交互与体验(ZCode 式顺滑的四个来源)

1. **命令面板 Ctrl+K**:全局键盘直达 8 个命令(6 页面导航 + 召唤奥粒 + 清空记忆),↑↓/Enter/Esc 全键盘操作,支持别名搜索(如搜"llm"到模型中心);
2. **Ctrl+J 一键召唤**:任何页面唤起奥粒;Esc 收起;
3. **流式打字机**:回复 16ms/2字 逐段揭示 + 光标闪烁,等待期三点跳动指示——"永远知道它在干什么";
4. **渐进披露 + 即时反馈**:快捷指令芯片(带做游戏/选模型/剧情卡住/你能做什么 + 两个直达导航),槽位芯片实时显示当前模型/离线态,历史本地落盘(`oriera.copilot.v1`,最近 40 条,命令面板一键清空)。

## 四、降级链(与引擎一致的四级)

```
用户输入 → copilot_chat(当前 provider) 
  ├─ 成功 → 流式回答
  ├─ 未配置 provider → 规则应答 + 引导去模型中心(不附技术细节)
  ├─ 调用失败(网络/超时/厂商错) → 规则应答 + 附一行原因(截断 90 字)
  └─ 浏览器调试模式(invoke 不存在) → 同上,标注"浏览器调试"
```
规则应答为确定性关键词匹配(新手起步/模型/剧情/3D 资产/快捷键/导出/兜底引导),同输入同输出——可回归测试。

## 五、隐私与治理

- 对话历史仅存本机 localStorage,可一键清空;不上报、不进引擎仓库;
- system prompt 不注入任何用户隐私;发给厂商的仅当前会话(最近 12 条截断);
- v2 工具调用落地时,动作分级:只读(读项目状态)免确认;写操作(建项目/改剧情)需用户点确认——ZCode 的权限模式思想。
