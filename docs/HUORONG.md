# 火绒安全兼容说明

## 现象

在装有**火绒安全**（及其防护组件 usysdiag.exe / wsctrl11.exe）的电脑上，OriEra Studio 里通过「🪟 独立窗口」打开的游戏/引擎 Demo 窗口会**白屏**：页面加载了但画面不出（3D 区域全白），右侧对话面板可能正常。

## 原因

火绒的网络防护会拦截 WebView2（Windows 系统内嵌浏览器组件）中「运行时创建的子窗口」的页面导航——对 `127.0.0.1` 本机地址也会误判取消。这与 OriEra 的代码无关（v0.3.2 至最新版全部如此；未装火绒的机器一切正常）。

## 解决（任选其一）

1. **信任区（推荐，一劳永逸）**：打开火绒 → 「信任区」→ 添加 → 目录 → 选择 OriEra Studio 的安装目录 → 确定。
2. **换用浏览器游玩（零配置）**：项目卡片上的「▶ 运行」主按钮默认在**系统浏览器**里打开游戏，完全不受影响。
3. 安装 v0.7.1 起，安装器与首次启动会**自动检测火绒并提醒**。
