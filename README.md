# OriEra Studio

> **OriEra 世界引擎官方辅助工具** —— 双击打开，无需科学上网、无需 GitHub、无需命令行，让每一位探索者都能零门槛用上 [OriEra 世界引擎](https://github.com/OriEra-engine/engine)。

**这是什么**：面向普通用户的桌面端工作台（Windows）。引擎本体在 [OriEra-engine/engine](https://github.com/OriEra-engine/engine)（Rust 11 层架构）；本仓库只做一件事——把引擎能力打包成人人可用的形态：内置引擎示例快照离线运行、五步生成自己的 AI 原生游戏原型。**本工具不替代引擎**，是引擎生态的上层易用性封装，后续引擎 L5/wgpu 渲染内核与 L7 原生推理落地后，本工具的注入层可直接对接。

## 反馈链路

Studio 桌面端内置「反馈直达引擎仓库」入口（设置页 → 📮 反馈直达引擎仓库）：提交时自动附带环境信息（版本/系统/GPU），
- 普通用户：一键跳转 GitHub 预填 issue 页（也支持本地存档手动投递，无 GitHub 条件也能反馈）
- 协作者：配置 PAT 后一键直提 [OriEra-engine/engine issues](https://github.com/OriEra-engine/engine/issues)

## 解决什么问题

用 OriEra 世界引擎做 AI 原生游戏原本需要：科学上网 + 会用 GitHub + 装工具链 + 命令行操作。
OriEra Studio 把这些全部封装掉：

| 门槛 | Studio 的解法 |
|---|---|
| 需要科学上网 | 引擎快照内置安装包；模型走国内直连端点（智谱/DeepSeek）/ 本地 Ollama |
| 需要用 GitHub | 零 git 依赖；引擎源码获取有 gitee 镜像引导（可选的开发者模式） |
| 操作繁琐 | 五步向导：选玩法 → 定剧情 → 植入模型 → 配 NPC → 生成即玩 |

## 功能

- **Demo 演示厅** — 内置引擎全部 11 个示例（含 AI 咖啡馆旗舰 demo），一键运行
- **模型中心** — 硬件体检（CPU/内存/显存）→ 云端/本地双轨推荐 → 一键植入引擎；API Key 存系统凭据管理器；保存后所有运行中游戏热切换，无需重启
- **本地大模型** — Ollama 检测/启动/按显存推荐档位/一键拉取（带进度）/删除模型/显存占用监控
- **玩法模板库** — 15 个精选玩法包（地牢肉鸽、卡牌构筑、生存建造、塔防、模拟经营、叙事冒险、视觉小说、沉浸模拟、开放世界、社交推理、放置挂机、动作闯关、解谜、宠物养成、沙盒 UGC）；支持从外部 JSON 导入自制玩法包
- **叙事框架库** — 三幕式、英雄之旅、群像剧、循环叙事、涌现式叙事；支持接 AI 现场定制剧情
- **新建游戏向导** — 5 步生成可运行原型：Three.js 3D 场景（4 种主题）+ AI NPC（带长期记忆）+ 剧情导演系统 + 玩法图鉴 + 金币经济循环
- **剧情编辑器** — 项目生成后可单独改剧情：前提/节拍增删移/AI 单拍重写（带上下文与自定义指令），历史自动备份
- **我的项目** — 项目列表、运行、打开目录、删除、导出分享 zip、运行时一键升级（老项目吃到新运行时特性）

## 技术栈

Tauri 2（Rust 后端）· Vue 3 + Naive UI · axum 内嵌静态服务器 · 引擎 kernel.js（L7 provider / L9 记忆系统复用）

## 开发

```bash
npm install
npm run tauri dev    # 开发
npm run tauri build  # 打 NSIS 安装包
```

目录结构：

```
engine-snapshot/   内置引擎快照（examples，随包分发）
src-tauri/         Rust 后端：静态服务器/硬件检测/模型推荐/项目生成/Ollama
src-tauri/runtime/ 生成游戏的运行时模板（index.html 注入数据）
src/               Vue 前端（六大页面 + 模板数据）
```

## 生成物说明

生成的游戏原型是**可运行的纯静态项目**：`index.html`（运行时）+ `game.json` + `story.json` + `agents.json` + `provider.json` + `README.md`。
原型在 Studio 内运行时自动注入模型（复用引擎 L7 `createProvider` 机制与 L9 `MemoryStore` 记忆）；脱离 Studio 打开时自动降级为离线性格引擎。

引擎完整渲染内核（L5/wgpu）仍在路线图中——当前原型基于 Three.js 演示层，届时可平滑升级。
